Introducing LightDecision-1An Open-Vocabulary Probabilistic Multimodal Decision Model.

Decision models are becoming an important category in AI. While large language models excel at generating text and reasoning through complex problems, decision models focus on structured outputs. Making judgments, classifying inputs, and choosing actions at low cost and high performance opens up a wide range of applications.

Today, we introduce LightDecision-1, a new model for fast decision-making and scoring. It accepts text, images, and candidate options described in natural language. A dedicated decision head evaluates the options jointly, providing a single probability interface for text-based judgments and visually grounded actions. Its capabilities span general decision-making, tool calling, visual evaluation, games, and embodied action selection. We offer 4B and 27B variants. Both support open-vocabulary options without an architectural limit on their number. They model semantic relationships among options while remaining equivariant to their order. Together, these properties enable strong performance across text decisions, soft-label probability prediction, games, and embodied environments.

02 / Inference latency

Share computation. Score options in parallel.

All options in a decision share the same observation and question. LightDecision-1 first computes this shared prefix, then processes the option branches in parallel microbatches. The decision head brings the full candidate set together and outputs probabilities directly. Reusing text and image encodings across options avoids redundant computation. This parallel strategy substantially reduces latency for long contexts and image inputs.

03 / Probability calibration

Confidence that reflects reliability.

A useful decision model should make accurate choices and express how reliable those choices are. When it assigns 80% confidence, the corresponding decisions should be correct about 80% of the time. On MMDM, we group predictions by the probability assigned to the chosen answer and compare them with observed outcomes. Curves below the diagonal indicate overconfidence; curves above it indicate underconfidence.

On hard-label tasks, most models are overconfident in the medium- to high-confidence range. In its highest-confidence bin, LightDecision-1 27B assigns an average probability of 97.6%, compared with an observed accuracy of 91.0%, leaving a calibration gap even for its most confident decisions. 4B stays closer to the diagonal in the 0.4–0.7 range, with gaps of approximately 1.8–3.5 percentage points.

Soft-label tasks allow multiple options to be plausible to different degrees. The vertical axis therefore measures the mean target probability of the chosen answer. LightDecision-1 27B is particularly effective at expressing this uncertainty. In the 0.2–0.6 confidence range, which covers approximately 90% of samples, its predictions differ from the target probabilities by around 1.6–5.0 percentage points. By comparison, Jev 1.14 underestimates target probabilities by about 12–17 percentage points in the 0.2–0.5 range, while Microsoft Decision-1 is markedly overconfident in its main confidence bins. This pattern is consistent with LightDecision-1 27B achieving a lower MMDM-Soft Brier score than the other models in this evaluation.

04 / Generalization to more options

From 77 options to 1,024.

Candidate sets change constantly in real applications. Tool libraries grow, action spaces expand, and new options emerge as the state changes. LightDecision-1 encodes natural-language options with shared parameters and evaluates them as a dynamic set, extending learned decision-making capabilities to larger candidate spaces.

Post-training used 116K SFT examples and 126K RL contexts. Text data came from OpenJevData-140k, supplemented with private multimodal data. Both stages used at most 77 options per context. On MMDM, LightDecision-1 scales to 255, 256, 512, and even 1,024 options. Despite never seeing candidate sets this large during post-training, the 27B model outperforms Jev 1.14 across these evaluated set sizes. The model can thus make native joint decisions over candidate sets far larger than those used in post-training.

05 / Architecture

Shared context. Joint decisions.

Building on our earlier OpenJev architecture, LightDecision-1 reads query and option representations from the contextual hidden states of Qwen3.5. In the example below, the shoes are tan, but the listing says black. The model encodes the image, listing, and query once. The color field, product type, and “none of these” each get their own branch from that shared prefix.

The head projects the query and options into a dedicated decision space and adds the query vector to each option. Two bidirectional set-attention blocks let the options exchange information. A bilinear readout scores each updated option against the query, and softmax converts the scores into a distribution.

Open vocabulary, dynamic candidate sets

Each option is supplied in natural language. Adding one introduces a new row in the set. The head has no output parameters tied to a class or set size. In practice, memory for cross-option attention limits the set size.

Reuse computation for the same state

The image, state, and query are encoded once. Each branch reuses the attention keys and values and recurrent states, then processes its own option description in parallel.

Reorder the options, preserve the judgments

The set blocks share parameters across options and have no option-position embeddings. Reordering the inputs reorders the probabilities along with their options.

Understand relationships between options

The meaning of “none of these” depends on the other options. Bidirectional attention lets each option read the others, so adding one can change the relative scores of those already in the set.

06 / Embodied tasks and games

Decision-making for real-time interaction.

Interactive tasks repeat the same loop: observe the environment, consider the goal and history, and choose the next action. LightDecision-1 takes actions and their conditions as candidate inputs, bringing visual understanding and action selection into a single probability interface.

In embodied environments, this interface supports comparing next actions, checking their preconditions, and assessing task completion. In games, it supports movement, interaction, and control-parameter selection. The aim is to sustain a sequence of decisions at low cost as the environment changes.

07 / Post-training

Learning to choose and to assign probabilities.

We train LightDecision-1 in two stages. Supervised fine-tuning (SFT) uses 116K decisions, about 80% with hard labels. Reinforcement Learning for Calibrated Decisions (RLCD) uses 126K contexts, about 30% with hard labels. We favor SFT for visual questions and pairwise preferences with a clear answer. Robot and game decisions with several plausible actions receive more emphasis in RLCD.

Both stages update the language backbone and the decision head while keeping the vision backbone frozen.

SFT with a common target distribution

A single correct option gets all the target probability. Equally valid options share it evenly. For soft labels, we normalize votes, observed frequencies, or known event probabilities over the valid options. SFT minimizes cross-entropy with this distribution and gives each decision equal weight in the batch.

RLCD with binary outcome feedback

If two outcomes occur 70% and 30% of the time, always choosing the first maximizes the expected match rate. To learn the frequencies themselves, RLCD combines squared error and log loss. The score is minimized when the prediction matches the target distribution.

RLCD uses matches to estimate the part of the gradient that depends on feedback. A hard label gives the outcome directly. For a soft label, we draw one outcome from the target distribution. We sample options independently of that outcome, so an option with a target probability of 30% matches the outcome 30% of the time when drawn. One forward pass scores all the options. We mix the predicted distribution with 10% uniform exploration and draw 16 options independently with replacement. We compare each draw with the same outcome and average over the draws. This reduces variability from option sampling while reusing the same model scores.

We differentiate the prediction-only term and the KL penalty to the frozen SFT policy exactly. For the remaining gradient, importance weighting corrects for the sampling distribution, and a leave-one-out baseline uses the other 15 draws to reduce variance. Averaging over outcomes and option draws recovers the gradient of the regularized objective.

RLCD objective and gradient

The excess scoring loss is the sum of a squared distance and a KL divergence. Training also penalizes deviation from the SFT reference policy.
